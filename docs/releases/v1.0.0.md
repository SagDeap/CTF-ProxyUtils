Первый стабильный релиз CTF-ProxyUtils объединяет TCP/UDP-пробросы, failover и объяснимый анализ трафика.

- Поддержка UDP с отдельными клиентскими сессиями, idle TTL, статистикой, записью датаграмм и анализом payload.
- Настраиваемые TCP, payload и HTTP health-check. Для HTTP доступны метод, путь, Host, заголовки, body, статус и text/hex/regex-проверка ответа.
- Раздел «Риски»: встроенные эвристики автоматизированных клиентов, traversal, injection и всплесков соединений.
- Пользовательские text/hex/regex-детекторы с направлением, HTTP-областью, фильтром правил, баллами, регистром и маскированием чувствительных совпадений.
- Суммарная оценка 0–100, объяснение каждого сигнала и автоматическое закрепление записей высокого риска.
- Импорт и экспорт профилей правил, детекторов и сканера. Токен панели не экспортируется; dry-run проверяет профиль до применения.
- Версионированный API `/api/v1`; прежние `/api`-маршруты правил и сканера сохранены как алиасы.
- Переработанная краткая документация, OpenAPI 3.1 и отдельные SVG-схемы основных потоков.
- Расширены регрессионные тесты для детекторов, health-check, UDP, API и миграции конфигурации.

Конфигурации v0.2.0 совместимы. Старые правила автоматически получают `protocol: tcp`, health-check типа `tcp` и значения новых лимитов по умолчанию.

Трафик, находки, события и метрики остаются в памяти до перезапуска. TLS не расшифровывается. Выберите бинарник под ОС и архитектуру; SHA-256 находятся в `checksums.txt`.
